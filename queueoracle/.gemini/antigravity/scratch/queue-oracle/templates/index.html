QUEUE ORACLE

AI-Powered Smart Hospital Queue and Resource Prediction System

"Queue Oracle does not just show what is happening in a hospital. It predicts what could happen next and helps hospitals prepare."

Modular Architecture
  • Frontend: HTML5, CSS3, JavaScript (ES6), Bootstrap 5, Chart.js.
  • Backend: Python 3, Flask REST API, CORS.
  • Machine Learning: Scikit-Learn Random Forest Regressor, Linear Regression, Moving Average Time-Series.
  • Database: SQLite3 with relational foreign keys and transaction integrity.
  • Persistence: Models saved as Joblib artifacts (`wait_time_rf.joblib`).
3rd Semester Hackathon Talking Points
  1. Dynamic Delay Cascade: When a doctor's consultation runs over by 25 mins, downstream waiting times update automatically.
  2. Intelligent Doctor Rebalancing: Detects when Doctor A has 16 patients while Doctor B has 3, calculates wait time savings, and executes reassignment upon approval.
  3. Hospital Bed Horizon Forecasting: Hourly admission vs discharge balancing forecasts saturation 1 to 4 hours in advance.
  4. Epidemiological Surveillance to Inventory Link: Spikes in Dengue cases immediately flag impending stockouts in NS1 Rapid Kits and IV fluids.
